# 13.1 Invoice Reads

Delivered the isolated invoice read-only API slice in the two owned files.

1. Created `src/billy_mcp/api/invoice_reads.py` following the established typed
   FastMCP read-module pattern: strict Pydantic inputs, only the frozen
   `/invoices` GET routes and allowlisted query surface, opaque invoice payload
   models, optional `meta.paging`, and `ToolError` propagation from the locked
   `BillyHttpClient`.
2. Encoded documented invoice list enums locally (sort property, sort direction,
   and state) while retaining documented period values as unparsed strings;
   reject undeclared inputs through Pydantic rather than passing them to HTTP.
3. Added focused mock-transport contract tests for escaped relative paths,
   full allowed-query serialization, malformed/unknown input rejection,
   singular/list root mapping with optional paging, both mapped 401 envelopes,
   and registration of exactly the two invoice tools.
4. Ran Ruff formatting/checking, Pyright, the focused test module, and the
   node lint/test scripts. Inspect the resulting diff to ensure only the two
   owned product files are staged for the subsequent commit.

Leaf decision: no child can be spawned because all descendant limits are zero;
this small, tightly coupled module-and-test change is completed locally.
