# 35.1 Catalog ticketed write tools

Implement the catalog leaf alone because node limits are depth 0, children 0,
and descendants 0. Use the frozen Wave-5 contract and the integrated shared
write protocol; no additional research, server wiring, or coverage edits.

1. Add `catalog_writes.py` with strict Pydantic outer preview models and one
   `register_catalog_write_tools` helper. Register six preview/execute pairs
   with flat direct parameters, ticket-only executes, relative collection paths,
   and opaque payload dictionaries.
2. Build each `WriteOperationSpec` solely from the corresponding server-known
   operation: products use `product`/`products` and preserve `productPrices` as
   an additional changed root; prices use `productPrice`/`productPrices`. Bind
   canonical POST/PUT bodies, bodyless DELETEs, escaped IDs, and explicit effect
   summaries through the shared protocol.
3. Add mocked FastMCP contract tests for all twelve schema surfaces, strict
   inputs, mutation-free previews, exact HTTP methods/paths/bodies, ticket
   invalid/expiry/replay outcomes, empty-token no-network handling, typed
   401/404 propagation, absent deleted-record metadata, and embedded product
   prices surviving the multi-root response mapper.
4. Run the focused catalog-write suite, the inherited non-live test script, and
   lint from the resulting committed bytes. Preserve root-owned fail-closed
   coverage state and report the commit SHA plus exact evidence to the parent.
