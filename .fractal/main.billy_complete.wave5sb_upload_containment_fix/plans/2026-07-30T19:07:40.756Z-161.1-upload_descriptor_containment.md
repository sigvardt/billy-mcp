# 161.1 Upload descriptor containment repair — delivered

Delivered descriptor-level containment repair with deterministic terminal and
intermediate symlink-race verification.

## Delivered scope and approach

This leaf cannot delegate: depth, child, and descendant limits are all zero.
The repair was limited to the owned upload service and its focused tests.

1. Replaced execute's path-based read after identity validation with a
   descriptor-relative traversal from each canonical configured upload root.
   Open every directory and the terminal regular file with no-follow semantics,
   obtain metadata from the terminal descriptor, compare it to the preview
   identity, then read and hash the transport buffer from that descriptor.
2. Preserved the existing consume/discard order and error contract. A changed
   in-root file remains `FILE_CHANGED`; descriptor traversal failures that
   reveal a symlink/non-regular escape return `FILE_NOT_ALLOWED`; neither path
   can call the HTTP client.
3. Replaced the obsolete `Path.read_bytes` race regression with deterministic
   descriptor-open hooks.  Cover a terminal same-digest symlink to an
   outside-root file and an intermediate-directory swap to an outside symlink,
   each proving zero transport requests.  Retain the existing binary-body,
   ticket, redaction, header, expiry, replay, and changed-file coverage.
4. Ran the focused upload tests, lint, and the node test script. The focused
   test also passed from a clean `git archive` checkout of `54b4579`.

## Post-Mortem

### Accomplishments

- Replaced execute's path-based read with no-follow descriptor traversal rooted
  at the configured canonical upload roots.
