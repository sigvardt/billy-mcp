## Implementation

1. Replace the nested `input` handler parameters with direct FastMCP fields:
   `contact` for create, `id` plus `contact` for update, `id` for delete, and
   `confirmation_ticket` for every execute. Construct the existing strict
   Pydantic preview/execute models inside the handlers before delegating to the
   existing `WriteProtocolService`.
2. Preserve the six-tool module helper and make every `server.tool` registration
   name a literal required tool name so the paired execute registrations are
   statically visible. Keep create/update `{ "contact": payload }`, escaped
   update/delete identifiers, and bodyless delete entirely in the shared
   protocol.
