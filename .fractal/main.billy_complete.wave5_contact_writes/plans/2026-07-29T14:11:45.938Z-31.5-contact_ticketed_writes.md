## Implementation

1. Add typed, `extra="forbid"` create, update, and delete preview input models.
   Create/update contain an opaque contact object; update/delete also require a
   non-empty id. Keep all summaries and errors free of business payload values.
2. Add `register_contact_write_tools(server, client, write_protocol)` as the
   sole registration path. Register exactly the six required names. Preview
   handlers construct `WriteOperationSpec` values for `/contacts`,
   `contact`/`contacts`, POST/PUT/DELETE, and delegate to `preview`; execute
   handlers accept only `WriteExecuteInput` and delegate to `execute`.
3. Bind create/update to `{ "contact": payload }`; bind delete's ticket to
   `{ "id": id }` while leaving its HTTP body `None`. Let the shared protocol
   retain ticket, path escaping, locked client, no-retry, and response mapping
   responsibilities.

2. Exercise preview through the registered tools and assert no request was
