### 4. Verdicts

For each of the five inventory ops, write:

- inventory id
- official endpoint/method and Supports claim
- documented request/response fields (from property tables only; no invented
  schemas)
- filters/pagination if applicable (likely N/A for writes)
- documented/observed errors
- sensitivity notes (org/user identity, tax return data, association links)
- method-gate result and interpretation (401 open-at-auth vs 405 closed)
- cleanup limitations (especially association DELETE 200 ≠ cleanup)
- **recommend** freeze-defensible future tool shape **only if** docs + gate
  support offline ticketed write; else **block** with explicit blocker
- exclusions: bulk, live, UI, vision, webhooks, invented relations

Authority layers must stay labeled:

1. Official-doc facts
2. Unauthenticated gate evidence
3. Unproven live/UI behaviour (never asserted as proven)

Global page disclaimer: research is not freeze acceptance, implementation,
contract test, live test, UI/vision verification, or completeness claim.

### 5. Recommend vs block heuristics

| Gate + Supports | Likely verdict |
| --- | --- |
| Supports method + unauth POST/PUT 401 | **Recommend** offline ticketed freeze candidate (preview+execute shape), still not freeze ACCEPT |
| Supports method + unauth 405 | **Block** offline tool until docs or authenticated non-prod evidence |
| DELETE 200 meta-only without cleanup proof | **Block** as implementable green; may note meta shape only if recommending later study — default block for product freeze |
| Bulk / ambiguous | **Block** / out of scope |

For `invoiceReminderAssociations.delete`: prior lead is DELETE 200 on missing
id. That reconfirms method-open narrative for singular delete but is **not**
cleanup success and **must not** alone justify a freeze-ready green product
contract. Prefer **block** for freeze/product until authenticated non-prod
delete of a real association proves cleanup, unless official docs give a full
singular-delete contract and project policy explicitly allows meta-only offline
delete freezes like bank-line associations. If sibling bank-line association
deletes were frozen offline on 200 meta-only + Supports delete, compare that
precedent carefully and decide consistently; if policy forbids inferring
cleanup, still **block** or recommend only with hard cleanup exclusions.
