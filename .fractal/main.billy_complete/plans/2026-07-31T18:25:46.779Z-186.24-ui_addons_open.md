## Contract freeze (research123 addons shell)

### Tool

- **Name:** `ui_addons_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  partner id, credential, local file path, digest, destination, or write/install
  payload.
- **Success:** non-PII only:
  - `path_class`: `/:org_slug/add-ons` (optional query params allowed; product
    may always report the canonical class without query for dual-session
    stability, matching exports/reports pattern). Soft aliases and nested
    paths are **not** success.
  - `heading`: `Fordele`
  - `shell_markers_present`: bool for shell markers (h1 Fordele + hub chrome
    such as partner card structure and/or known section labels **without**
    dumping page text, org names, person names, or partner customer data).
  - Optional observe-only bool fields if useful for tests (e.g.
    `partner_hub_observed`) but **no** required click-side-effect fields.
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (Upsedasse/error shell, soft aliases
  including `addons`/`integrations`/`apps`/nested/settings/*, wrong path class,
  missing h1 Fordele, plan-gate classification if ever observed as sole state).
- **Never:** install, connect, enable, configure partner, create access token,
  apply for loan, or follow external partner destinations.

### Navigation

1. Ensure authenticated READY session via existing browser auth path.
2. Prefer direct `https://mit.billy.dk/{org_slug}/add-ons`.
3. Optional recovery: harvest dashboard/nav link text `Udforsk integrationer`
   only if it resolves to path class `/:org_slug/add-ons` (same as research123).
4. Independent second session (fresh profile or equivalent) re-opens the same
   path and asserts path/h1/title class match. **No** API read-back.
