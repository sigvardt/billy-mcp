- **Name:** `ui_vat_declarations_list`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  period, credential, local file path, digest, destination, or write payload.

    (column header and/or body marker).

  missing h1, classification failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens,
  VAT amounts, or customer PII.

  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Direct goto `https://mit.billy.dk/{org_slug}/vat-declarations` (research120
     freeze target). Do **not** treat soft aliases as success.
  5. Classify path with regex equivalent to
     `^/[^/]+/vat-declarations$` (optional query params allowed).
  6. Signature: path class match + h1 `Momsangivelser` + not login + not
     Upsedasse/error shell + Periode chrome (header or body). Empty table body
     is **valid**.
  7. Reject soft aliases (`vat`, `moms`, `vat_declarations` underscore,
     `sales-tax-returns`, …) and sibling paths as `UI_CHANGED` for this tool.
- **Hard bans:** never click Indsend / Opret / Ny angivelse / Eksport /

  sibling families as success; never call live API.
- **Session:** no API token; no screenshot persistence in production tool path;
