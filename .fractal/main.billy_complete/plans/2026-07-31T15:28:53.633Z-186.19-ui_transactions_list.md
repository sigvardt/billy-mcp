## Contract freeze (research118)

### Tool

- **Name:** `ui_transactions_list`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  transaction id, filter, credential, local file path, digest, destination, or
  create payload.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/transactions` (Billy may append query
    such as `period=…`; path class remains the list class).
  - `heading`: `Posteringer`
  - `create_action_visible`: bool true when **Ny postering** is visible
    (observe only; never click).
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Fakturaer / Udgifter / Menu / Bank / Bilag /
    Regnskab / Bogføring / Rapporter) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (Upsedasse/error shell, create shell
  `Postering:`, soft alias path, wrong path class, missing h1/CTA,
  classification failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens, or
  customer PII.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Direct goto `https://mit.billy.dk/{org_slug}/transactions` (research118
     freeze target). Do **not** navigate to `/transactions/new` as success.
  5. Classify path with regex equivalent to
     `^/[^/]+/transactions$` (optional query params allowed; path class remains
     `/:org_slug/transactions`).
  6. Signature: path class match + h1 `Posteringer` + `Ny postering` visible +
     not login + not Upsedasse/error shell + shell markers. Do **not** require
     HTML `table` / `role=grid` (research118: counts 0; custom list chrome).
  7. Reject create shells (`/transactions/new`, `/empty`, `/list`, … with h1
     `Postering:`), soft aliases, and daybooks paths as `UI_CHANGED` for this
     tool.
- **Hard bans:** never click Ny postering / Bogfør / Godkend / Slet / Rediger /
  void; never fill create form; never call invent API tools; never treat
  create shell or daybooks editor as success for this tool.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
