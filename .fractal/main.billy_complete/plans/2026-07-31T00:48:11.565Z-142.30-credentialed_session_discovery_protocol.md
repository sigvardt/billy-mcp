non-sensitive project-wiki contract. This is the only authorised interface-lane
deliverable while dedicated non-production browser credentials and organisation
identity are unavailable. It must neither invent a post-login selector or tool
nor change coverage state.

## Acceptance criteria

- The wiki provides a clear, non-sensitive runbook for the first credentialed,
  headless discovery without storing a credential, token, organisation value,
  cookie, DOM dump, frame, HAR, trace, or business data.
- It distinguishes observed login-only facts from future discovery outcomes and
  forbids both selector invention and coverage greening.
- It keeps API hosts denied to the browser lane and prohibits a credentialed
  API call for read-back or qualification.
- Cross-links resolve cleanly; the memory state stays current and no source,
  test, coverage, dependency, or generated evidence file changes.
- The next implementation remains explicitly gated on a fresh Grok
  credentialed-discovery brief and the dedicated non-production secrets.
