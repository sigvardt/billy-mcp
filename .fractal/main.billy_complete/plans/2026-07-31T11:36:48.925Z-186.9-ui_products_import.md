## Contract freeze (research108)

### Tool

- **Name:** `ui_products_import`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  file path, digest, filter, credential, or customer fields.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/products/import`
  - `heading`: literal `Import af produkter`
  - `choose_csv_action_visible`: bool for exact control label **`Vælg CSV-fil`**
    (presence only; never click; never set files)
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Menu / Produkter / Import) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path, missing h1 /
  required control), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens,
  product names, CSV contents, or customer values.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Goto `https://mit.billy.dk/{slug}/products/import` (same wait policy as
     products / recurring list shells).
  5. Classify with path regex `^/[^/]+/products/import$` (query params allowed
     if Billy adds them; path class remains `/:org_slug/products/import`).
  6. Signature: h1 text `Import af produkter` and visible `Vælg CSV-fil`
     (button or role=button / file-chooser trigger; prefer visible text match
     used for other CTAs; do not require a durable `data-cy` unless observed).
  7. Reject alias paths (`product-import`, `product_import`, bare `import`)
     as `UI_CHANGED` if somehow navigated.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
