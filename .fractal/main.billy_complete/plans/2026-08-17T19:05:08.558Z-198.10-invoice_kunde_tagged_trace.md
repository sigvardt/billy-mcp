## Design choices

1. **TDD first (`728BD2E4`).** First product edit is a failing unit
   fixture. Current live opener and overlay `after_click` fail
   `kunde_trace_missing_keys`. Run it. Capture the failure. Then
   implement. Do not reuse picker-inventory or DIV-ownership keys
   as the new fixture.
2. **Honesty-16 stays red.** Confirm the coverage gate still
   length 16 before any other edit.
3. **Keys are flags, counts, allowlisted tokens, and integer
   timing.** Never store bodies, raw URLs, query strings, tag text,
   ids, accessible names, CSS urls, or pixels in git.
4. **Listeners first.** Attach request + response + console/pageerror
   handlers on a fresh page **before** `goto /invoices/new`.
   `listener_attached_before_form=true` only when that order holds.
5. **`path_class`.** Derived from path prefix only:
   `contacts` (`/v2/contacts`), `invoices` (`/v2/invoices`),
   `other_v2` (`/v2/`), `other_same_origin` (mit.billy.dk or
   api.billysbilling.com otherwise), `denied` (blocked). Method is
   the HTTP verb. Status is the response status or 0 if no response.
   `timing_ms` is an int. Cap `requests` at 32.
6. **Instrumented click + type are allowed once.** Center click the
   proved `input[name=contact]` (not the overlay `DIV`). Then type
   the exact FastMCP tag. This is not a `51E18E60` uninstrumented
   repeat: listeners are already attached and the customer exists
   in a second session.
7. **Named next action.** True only when after click or after type
   the dump shows at least one of: a `contacts` `path_class`
   request, `portal_inserted=true`, `option_role_count>0`, or
   `aria_expanded_present=true`. Then one normal Playwright action
   that the trace named. Otherwise `UI_CHANGED` and stop.
8. **Cleanup.** Delete the tagged customer through FastMCP in a
   fresh session. Prove absence. Do not leave `MCP-UI-INV-*`
   contacts.
9. **Do not remap.** Preview `tool_name` waits for a later slice
   after independent accept + purge.
10. **Vision.** Live test may write `author=live_test` and
    `reviewer_verdict=pending_review` only. Field shot lives under
    `~/.local/share/billy-mcp/` and is purged after review.
