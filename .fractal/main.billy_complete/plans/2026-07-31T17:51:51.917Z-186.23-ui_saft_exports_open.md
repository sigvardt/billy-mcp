## Contract freeze (research122 saft shell)

### Tool

- **Name:** `ui_saft_exports_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  period, credential, local file path, digest, destination, or write/export
  payload.
- **Success:** non-PII only:
  - `path_class`: `/:org_slug/exports` (optional query params allowed; product
    may always report the canonical class without query for dual-session
    stability, matching exports/reports pattern). Nested
    `exports/saft*` is **not** required and must not be the only accepted class
    unless still classified as the exports hub (prefer strict canonical
    `/:org_slug/exports`).
  - `heading`: `Eksportér data`
  - `saft_export_cta_observed`: **required true** (button text
    `Eksportér som SAF-T` present; observe only). If CTA missing → `UI_CHANGED`.
  - `shell_markers_present`: bool for shell markers (h1 + export hub chrome
    and/or SAF-T button presence **without** clicking; never dump page text,
    org names, or customer lists).
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (Upsedasse/error shell, soft `saft*`
  aliases, singular `export`, reports-all/vat/annual/transactions/settings
  paths, wrong path class, missing h1, missing SAF-T CTA, classification
  failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens, or
  raw page dumps.
- **Non-claims:** soft empty `saft*` is not success; nested `exports/saft` SPA
  fallback is not a separate family; annual_reports Upsedasse stays red; no
  API invent; never click SAF-T/export/download.
