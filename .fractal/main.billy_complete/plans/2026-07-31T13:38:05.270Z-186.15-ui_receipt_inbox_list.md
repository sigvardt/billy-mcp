## Contract freeze (research114)

### Tool

- **Name:** `ui_receipt_inbox_list`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  filter, credential, local file path, digest, or destination fields.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/vouchers`
  - `heading`: literal `Bilagsindbakke`
  - `file_control_present`: bool true when `input[type=file]` count ≥ 1
    (presence only; never set / never click upload)
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Fakturaer / Udgifter / Menu / Bank / Køb /
    Leverandører / Bilag) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path, missing h1 /
  classification failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens,
  filenames, or attachment content.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Goto `https://mit.billy.dk/{slug}/vouchers` (same wait policy as
     uploads / creditor list shells).
  5. Classify with path regex `^/[^/]+/vouchers$` (query params if Billy adds
     any: allow; path class remains `/:org_slug/vouchers`).
  6. Signature: h1 text `Bilagsindbakke`.
  7. Reject alias paths (`inbox`, `receipts`, `receipt`, `kvittering`,
     `indbakke`, `voucher`, `bilagsindbakke`, `uploads`, …) as `UI_CHANGED`
     if somehow navigated for this list tool. Do **not** accept uploads/Bilag
     as success for this tool.
- **Hard bans:** never click Ret / Upload filer / Udfyld alle / Kom i gang;
  never set `input[type=file]`; never call API upload tools from this
  observation; never treat Bilag uploads shell as receipt inbox.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
