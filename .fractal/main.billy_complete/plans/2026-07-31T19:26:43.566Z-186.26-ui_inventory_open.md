## Contract freeze (research125 Lagermodul open shell)

### Tool

- **Name:** `ui_inventory_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  product id, credential, local file path, digest, destination, or write/create
  payload.
- **Success:** non-PII only:
  - `path_class`: `/:org_slug/inventory` (optional query params allowed if path
    stays inventory; product may always report the canonical class without query
    for dual-session stability, matching prior open shells).
  - `heading`: `Lagermodul` (exact)
  - `shell_kind`: literal `lagermodul` (or equivalent stable enum distinguishing
    dedicated content module from soft_empty / fordele / products_list)
  - `create_cta_markers_present`: bool true when Opret primo / Opret produkt /
    Opret status chrome is visible **as markers only** (no page dump, no org
    names, no person names).
  - Optional: `same_shell_as_products: false` if useful for contract clarity.
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` when any of:
  - landed on products path or h1 `Produkter`
  - soft aliases leaving inventory leaf (`lager`, `lagermodul`, `stock`,
    `warehouse`, nested `inventory/*`, `settings/inventory`,
    `products/inventory`, …)
  - Upsedasse / error shell / plan-gate as sole state / login form present
  - empty h1 soft-empty chrome on non-inventory success path mis-classified
  - heading not `Lagermodul` on inventory path
- **Never:** click Opret primo / Opret produkt / Opret status; invent
  `api_inventory_*`; treat products list as this tool.

1. Ensure authenticated READY session via existing browser auth path.

3. Do **not** navigate via products list or invent nested create URLs for
