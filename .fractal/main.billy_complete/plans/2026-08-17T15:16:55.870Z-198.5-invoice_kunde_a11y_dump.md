## Design choices

1. **TDD first (`728BD2E4` + `5E1EDFB4`).** First product edit is a
   failing unit fixture. The current live opener payload is
   incomplete. A helper must report the missing keys and refuse to
   name an opener. Run it. Capture the failure. Then implement.
2. **Honesty-16 stays red.** Confirm the coverage gate still
   length 16 before any other edit.
3. **Dump contract.** Resting dump records, as non-PII flags only:
   exact input (tag, type, id present, autocomplete present,
   disabled, readonly, each `aria-*` name present), ancestors until
   `FORM` (tag, id present, role, name, testid, class-token flags),
   label/for and wrapping-label flags, aria relationships, active
   element flags, roles/names/states, boxes, pointer-events,
   z-index, `elementFromPoint` at the input center. Never store the
   tag, raw placeholder, raw accessible name, or credentials.
4. **Live sequence.** Resting dump first. Then one normal click on
   that same field. Dump visible portal descendants. Type the tag.
   Dump portals again. Stop unless those dumps name one control.
5. **One derived action.** Only a control the dump named. No
   guessed sibling. No extra keys. If still unnamed, return
   `UI_CHANGED` and stay red.
6. **Do not remap.** Preview `tool_name` waits for a later slice
   after independent accept + purge.
7. **Vision.** Live test may write `author=live_test` and
   `reviewer_verdict=pending_review` only. A dump-only pass needs
   no accept record.
