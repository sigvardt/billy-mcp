## Contract freeze (research116)

### Tool

- **Name:** `ui_financing_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  filter, credential, local file path, digest, destination, or apply payload.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/financing`
  - `heading`: literal `Ansøg om erhvervslån` (required non-empty; research116
    dual-stable h1)
  - `apply_cta_observed`: bool true when marketing apply entry is present
    (e.g. text **Få et uforpligtende tilbud** and/or nav **Ansøg om lån**
    visible) — **observe only, never click**
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Fakturaer / Udgifter / Menu / Bank / Bilag /
    Regnskab / Afstemning / Bogføring / Rapporter) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path class, wrong/missing
  h1, classification failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens, or
  partner PII.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Prefer: direct goto `https://mit.billy.dk/{org_slug}/financing` (research116
     primary seed). Optional harvest of Bank nav **Ansøg om lån** href that
     classifies to `/:org_slug/financing` is allowed as equivalent path; do not
     require bank-accounts detour if direct path works.
  5. Classify with path regex equivalent to `^/[^/]+/financing$` (query params
     if Billy adds any: allow; path class remains `/:org_slug/financing`).
  6. Signature: path class match + h1 exact `Ansøg om erhvervslån` + not login
     + not error shell + shell markers. Do **not** require tables/forms.
  7. Reject soft subpaths (`financing/apply`, `financing/loan`, …) and alias
     seeds (`loan`, `finance`, `laan`, …) as `UI_CHANGED` for this tool.
- **Hard bans:** never click Få et uforpligtende tilbud / Ansøg nu / Fortsæt /
  Send ansøgning / Godkend / Acceptér; never toggle consent inputs; never call
  invent financing API tools; never treat bank-accounts or Afstemning as success.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
