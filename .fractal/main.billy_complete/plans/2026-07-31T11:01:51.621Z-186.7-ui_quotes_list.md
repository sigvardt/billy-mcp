## Contract freeze (research106)

### Tool

- **Name:** `ui_quotes_list`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  filter, credential, quote id, or customer fields.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/quotes` (canonical list shell class)
  - `heading`: literal `Tilbud`
  - `create_action_visible`: bool for exact CTA label **`Opret tilbud`**
    (presence only; never click)
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Menu / Tilbud) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path, missing h1 /
  required CTA), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens,
  quote numbers, balances, or customer values.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Goto `https://mit.billy.dk/{slug}/quotes` (same wait policy as bank accounts).
  5. Classify path/h1/CTA/shell markers; fail closed on Upsedasse / Log ind igen.
  6. **URL accept:** path regex `^/[^/]+/quotes(?:/empty)?$` — Billy’s empty
     state lands on `/{slug}/quotes/empty`; bare `/{slug}/quotes` also valid.
     Query params allowed. Success still reports canonical `path_class`
     `/:org_slug/quotes`.
  7. Do **not** require table rows (discovery table_count was 0).
