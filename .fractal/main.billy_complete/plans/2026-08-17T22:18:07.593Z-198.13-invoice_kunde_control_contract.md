## Design choices

1. **TDD first (`728BD2E4`).** First product edit is a failing unit
   fixture. Current live opener / `smallest_wrapper` flags fail
   `kunde_control_missing_keys`. Run it. Capture the failure. Then
   implement. Do not reuse `REQUIRED_KUNDE_TRACE_KEYS`,
   `REQUIRED_KUNDE_EVENT_KEYS`, or `REQUIRED_KUNDE_ROUTE_KEYS` as
   this fixture.
2. **Honesty-16 stays red.** Confirm the coverage gate still
   length 16 before any other edit.
3. **Already-loaded page only.** Open `/:org_slug/invoices/new`.
   Wait until `input[name=contact]` is present. Stop. CDP-inspect
   that input and its smallest wrapper. Do not click, type, or
   focus.
4. **CDP, not `evaluate` click.** Playwright
   `page.context.new_cdp_session(page)` then `DOM.getDocument` /
   `DOM.querySelector` / `DOM.resolveNode` /
   `DOMDebugger.getEventListeners`. `Debugger.getScriptSource` only
   for a `scriptId` the VM already parsed. Never `page.goto` or
   `fetch` a script or `/v2/` URL.
5. **Drop our counters.** Ignore listeners whose handler matches
   `KUNDE_EVENT_INIT_SCRIPT` / `__billyKundeEvents`.
6. **Keys are allowlisted tokens.** Event types:
   `click` / `focus` / `blur` / `input` / `change` / `keydown` /
   `keyup` / `mousedown` / `mouseup` / `pointerdown` /
   `pointerup` / `other`. Binding `token_class`:
   `name_eq_contact` / `name_quoted_contact` / `name_selector` /
   `contact_id` / `none`. Action token:
   `click_open` / `focus_open` / `input_filter` / `none`.
7. **Script locator.** `script_basename` is the last path segment,
   query stripped, hex runs ≥8 → `:id`. `script_hash` is 16
   lowercase hex of that basename. `line` / `column` are ints ≥ 0.
   Never store the url or source text in git.
8. **Wrapper attributes.** Commit `data-*` **names** only. Values
   omitted, or optional 16-char sha256 in
   `wrapper_data_attr_hashes`. Copy `wrapper_class_tokens` onto
   this dump so the fixture does not depend on the DIV dump.
9. **Binding search.** Search already-loaded source only for
   `name=contact`, `name:"contact"`, `name:'contact'`,
   `input[name=contact]`, `contactId`. Store one `binding_script`
   row or `null`.
10. **Named next action.** True only when a remaining listener
    type plus a non-`none` `token_class` maps to `click_open` /
    `focus_open` / `input_filter`. Generic Ember bubble with
    `token_class=none` is `UI_CHANGED`.
11. **No customer unless named.** Do not create `MCP-UI-INV-*`
    unless `named_next_action` is already true. Then one focused
    failing fixture for that exact action, the smallest fix, and
    one FastMCP CUD with fresh-session read-back and reverse
    cleanup. This iteration should expect `UI_CHANGED` unless the
    dump names an action.
12. **Do not remap.** Preview `tool_name` waits for a later slice
    after independent accept + purge.
13. **Vision.** Live test may write `author=live_test` and
    `reviewer_verdict=pending_review` only. Owner-only locators
    live under `~/.local/share/billy-mcp/` and are purged after
    review.
