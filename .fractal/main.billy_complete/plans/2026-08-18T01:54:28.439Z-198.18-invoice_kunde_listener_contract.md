## Design choices

1. **TDD first (`728BD2E4` / `28C8FBC8`).** Confirm honesty-16
   still length 16 and red. First product edit is a failing unit
   fixture. Current control dump flags (locator keys, inferred
   `click_open`) fail `kunde_listener_missing_keys`. Run it.
   Capture the failure. Then implement. Do not reuse
   `REQUIRED_KUNDE_CONTROL_KEYS` as this fixture.
2. **Honesty-16 stays red.** Do not remap invoice tools.
3. **Read-only first.** The live inspect does not need a tagged
   customer. Open `/:org_slug/invoices/new`. Hold the four hosts.
   Login through `create_server` `call_tool`. Inspect via a helper
   on a fresh observer page, same shape as `capture_kunde_fiber`.
4. **Not a locator remake.** `452E0773` already stored type,
   capture, basename, hash, line, column on input and wrapper.
   This contract stores classified action fields only. Locators
   stay transient.
5. **No subtree walk.** Call `getEventListeners` once per
   `objectId`. Do not pass `depth` or `pierce`. Overlay is the
   already-proved geometry descendant, not a new map.
6. **Source is transient.** `Debugger.getScriptSource` only for a
   `scriptId` returned by `getEventListeners`. Classify a short
   window around line and column. Delete the source before return.
7. **Unique normal action.** True only per the Goal count. A
   pointer or keyboard listener with `invoked_action_token=none`
   is not unique.
8. **Click / customer gate.** Create a tagged customer and
   perform one named UI action only after
   `unique_normal_action=true`. Else no customer, no click.
9. **No Leverandør compare yet.** If the dump is non-actionable,
   stop at `UI_CHANGED`. The bills structure compare is the next
   parent slice, not this one.
10. **Cleanup.** If a customer was created, delete it. Prove
    absence in a fresh session. Commit allowlisted summary only.
11. **Vision.** Live test may write `author=live_test` and
    `reviewer_verdict=pending_review` only.
12. **No remap.** Preview `tool_name` waits for a later slice
    after independent accept + purge.
13. **Live test short-circuit.** After the dump is delivered,
    later `ui-full` must verify the file and must not remake
    Ember, fiber, or a closed click.
