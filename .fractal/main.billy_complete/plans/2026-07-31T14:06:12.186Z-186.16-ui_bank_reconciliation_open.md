## Contract freeze (research115)

### Tool

- **Name:** `ui_bank_reconciliation_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  account id, filter, credential, local file path, digest, or destination fields.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/bank_accounts/:id/sync`
  - `heading`: observed h1 text when present, else empty string (test org is
    empty; do not invent a heading)
  - `empty_content_shell`: true when h1 empty **and** table count 0 **and**
    role=grid/table count 0 (current test org); false if loaded content appears
  - `afstemning_nav_visible`: bool true when Afstemning nav anchor remains
    visible/classifiable on the shell
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Fakturaer / Udgifter / Menu / Bank / Bilag /
    Regnskab) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path class, missing
  Afstemning harvest, classification failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens, or
  account ids.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Prefer: goto bank shell root if needed, then **harvest** the visible
     Afstemning `a[href]` (exact label match), navigate that href.
     Fallback only if harvest fails after settle: UI_CHANGED (do **not** invent
     account ids).
  5. Classify with path regex equivalent to
     `^/[^/]+/bank_accounts/[^/]+/sync$` (query params if Billy adds any: allow;
     path class remains `/:org_slug/bank_accounts/:id/sync`).
  6. Signature: path class match + not login + not error shell + dual-stable
     empty or loaded content fields. **Do not require** non-empty h1 (empty is
     valid in test org).
  7. Reject alias paths (`bank-accounts` list, `bank-reconciliation`,
     `reconciliation`, `afstemning`, `transactions/bank`, …) as `UI_CHANGED`
     for this tool. Do **not** accept h1 `Bankkonti` list shell as success.
- **Hard bans:** never click Forbind til bank / Importer / Match / write CTAs;
  never call bank write API tools from this observation; never treat
  `bank-accounts` Bankkonti as reconciliation success.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
