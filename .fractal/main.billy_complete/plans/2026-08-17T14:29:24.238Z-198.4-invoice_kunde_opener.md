   fixture: the live dump contract is not a bind.
   `wrapper_count=0` + `search_trigger=false` + `value_len==tag_len`

   `UI_CHANGED`. Run it. Capture the failure. Then implement.

   parent testid/class tokens, sibling search/caret counts, exact

   typeahead. Existing-option bind only after a visible option.
   Create footer last.
4. **Tagged contact first.** `ui_clients_create_preview` /
   execute, then invoice CUD, then invoice delete, then contact
   delete. Third-session absence for both.
5. **Observe before CTA changes.** Keep fail-closed

6. **PUT egress only after a failing test.** Prefix
   PUT `/v2/invoices/` only if live update is PUT and blocked.

7. **Vision provenance (`C7DBE974`).** Live test may write
   `author=live_test` and `reviewer_verdict=pending_review` only.
