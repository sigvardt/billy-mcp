## Implementation child

1. Commit this planning baseline, then initialise and start a child with
   `fractal node init wave5a_root_registration --path=<project-root> --agent=codex-power`.
2. Give it exclusive product ownership of:
   `src/billy_mcp/server.py`, `scripts/generate_coverage_report.py`,
   `tests/unit/test_coverage_server.py`, and generated `coverage/` artifacts.
   It may add a narrowly scoped registration test when it improves runtime
   proof. It must not alter write leaf modules, browser/UI/auth work, bulk rows,
   live flags, or completion state.
3. The child must create one `ConfirmationStore` and one `WriteProtocolService`
   per `create_server` call, register contact, contact-person, catalog, and
   daybook write groups, and expose exactly 124 `api_*` tools plus the two
   coverage tools.
4. It must add evidence only for the fifteen frozen clear CUD rows and regenerate
   the inventory/report. Expected generated state: `implemented=109`,
   `contract_tested=109`, `live_tested=0`, and `complete=false`; the 92 bulk
   rows retain empty tool names and every UI row stays red.
5. It must run formatting, Ruff, Pyright, the focused write/coverage suites,
   coverage-policy checks, and the non-live non-vision suite before committing.
   If it fails before any edit because Codex Power authentication, quota, or a
   rate limit blocks it, retry the complete child step through Grok; never switch
   agents after edits.

## Parent integration and review gate

1. Monitor the child, inspect its committed three-dot diff and clean-export
   tests, and merge only the accepted implementation artifacts with the labelled
   no-fast-forward merge.
2. Re-run the full local offline checks from the root and verify generated
   coverage counts and the 124-tool runtime registry.
3. Spawn an independent Grok review child against the integrated commit. It must
   validate current official-doc fingerprint, exact tool/ticket wiring,
   inventory evidence, fail-closed live/UI/bulk state, and test evidence. It
   must publish a cited, non-sensitive wiki verdict before any broader write
   cohort proceeds.
