## Contract freeze (research112)

### Tool

- **Name:** `ui_creditor_balances_list`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  filter, credential, contact, or amount fields.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/creditorbalance`
  - `heading`: literal `Skyldige udgifter`
  - `create_action_visible`: bool for exact control label **`Opret køb`**
    (presence only; never click)
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Fakturaer / Udgifter / Menu / Bank / Køb /
    Leverandører) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path, missing h1 /
  required control), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens,
  contact names, bill numbers, or balances.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Goto `https://mit.billy.dk/{slug}/creditorbalance` (same wait policy as
     debtor/bills list shells).
  5. Classify with path regex `^/[^/]+/creditorbalance$` (query params allowed on
     real URL; path class remains `/:org_slug/creditorbalance`).
  6. Signature: h1 text `Skyldige udgifter` and visible `Opret køb`.
  7. Reject alias paths (`creditor-balances`, `creditor_balances`,
     `creditorbalances`, `skyldige-udgifter`, `payables`, `accounts-payable`) as
     `UI_CHANGED` if somehow navigated for this list tool.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
