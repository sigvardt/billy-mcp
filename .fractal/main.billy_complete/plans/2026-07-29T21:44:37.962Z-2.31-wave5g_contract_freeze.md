## Delegation decision

The root-owned contract is a small, shared-wiki-only change and must be
committed before a child can inspect it, so it remains root-owned. The required
clean-context freeze gate is an independent `grok` child; it has a distinct
review artifact and no overlapping production files. A later `codex-power`
product child is intentionally sequential, because it must not start until the
freeze gate accepts. This is a management split, not a request to create
parallel speculative code.
