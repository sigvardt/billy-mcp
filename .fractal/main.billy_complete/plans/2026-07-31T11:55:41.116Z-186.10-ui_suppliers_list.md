## Contract freeze (research109)

### Tool

- **Name:** `ui_suppliers_list`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  filter, credential, or customer fields.
- **Success:** non-PII only:
  - `path_class`: literal `/:org_slug/suppliers`
  - `heading`: literal `Leverandører`
  - `create_action_visible`: bool for exact control label **`Opret kontakt`**
    (presence only; never click)
  - `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Udgifter / Menu / Køb / Leverandører) without
    dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path, missing h1 /
  required control), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens, or
  contact/supplier names.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Goto `https://mit.billy.dk/{slug}/suppliers` (same wait policy as clients /
     products list shells).
  5. Classify with path regex `^/[^/]+/suppliers$` (query params allowed on real
     URL; path class remains `/:org_slug/suppliers`).
  6. Signature: h1 text `Leverandører` and visible `Opret kontakt`.
  7. Reject alias paths (`supplier`, `vendors`, `leverandorer`) as `UI_CHANGED`
     if somehow navigated.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
