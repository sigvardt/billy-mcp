## Contract freeze (research129 user / Profil open shell)

### Tool

- **Name:** `ui_settings_user_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  credential, local file path, digest, destination, or write payload.
- **Success:** non-PII only:
  - `path_class`: `/:org_slug/settings` (canonical class without query; bare
    hub leaf; SPA does **not** keep `/settings/user`).
  - `heading`: `Indstillinger` (exact).
  - `shell_kind`: literal `settings_user`.
  - `user_panel_markers_present`: bool true when required markers are
    visible — require h2 / active panel set includes **`Profil`**, **`Billede`**,
    **`Sprog og tema`**, and **`Skift adgangskode`**.
  - Must be **distinct from company**: company panel h2 pair
    (`Navn og adresse` + `Kontaktinformation`) must **not** both classify as
    the active panel signature.
  - Must be **distinct from accounting**: accounting panel trio
    (`Regnskab` + `Køb` + `Kontoplan`) must **not** classify as success.
  - Must be **distinct from invoicing**: invoicing panel
    (`Faktura` + `Produkter` + (`Betalingsmetoder` or `Standard fakturalogo`))
    must **not** classify as success.
  - Optional observe-only: `save_cta_markers_present` when `Gem ændringer`
    text is visible (**no page dump**, no person names, emails, phone values,
    or password field values).
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`

    `settings/vat`, `settings/users`, `settings/list`,
    `settings/access-token`, `settings/beta`, `indstillinger`, …)
  - hub open but **wrong panel** (company default; Regnskab; Faktura;
    Momssatser; Brugere; Adgangsnøgler; Betas; empty Abonnement chrome)

  - sibling shells (Lagermodul, Fordele, Eksportér data, Overblik, products)
- **Never:** click Gem ændringer / Gem / Upload / password submit / Opret* /
  Tilføj* / Slet / Opgrader; invent `api_settings_*`; treat company,
  accounting, or invoicing open as this tool's success.
