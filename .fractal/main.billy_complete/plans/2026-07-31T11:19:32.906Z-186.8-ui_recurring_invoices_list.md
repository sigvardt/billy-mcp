- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  filter, credential, recurring id, or customer fields.

  subscription numbers, balances, or customer values.

  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Goto `https://mit.billy.dk/{slug}/recurring_invoices` (same wait policy as
     quotes / bank accounts).
  5. Classify path/h1/CTA/shell markers; fail closed on Upsedasse / Log ind igen.

     discovery observed bare `/{slug}/recurring_invoices`; optional `/empty`
     accepted for symmetry with quotes empty-state. Query params allowed.
     Success still reports canonical `path_class` `/:org_slug/recurring_invoices`.
