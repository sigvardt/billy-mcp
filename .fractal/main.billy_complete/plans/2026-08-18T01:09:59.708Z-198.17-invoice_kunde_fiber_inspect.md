## Design choices

1. **TDD first (`728BD2E4`).** Confirm honesty-16 still length 16
   and red. First product edit is a failing unit fixture. Current
   Ember dump flags (no fiber keys) fail
   `kunde_fiber_missing_keys`. Run it. Capture the failure. Then
   implement. Do not reuse `REQUIRED_KUNDE_EMBER_KEYS` as this
   fixture.
2. **Honesty-16 stays red.** Do not remap invoice tools.
3. **Read-only first.** The live inspect does not need a tagged
   customer. Open `/:org_slug/invoices/new`. Hold the proved
   contact `INPUT` and closest `.pickerfield`. CDP
   `Runtime.getProperties` only. Login through `create_server`
   `call_tool`. Inspect via a helper on a fresh observer page,
   same shape as `capture_kunde_ember`.
4. **Fiber lookup is not Ember lookup.** Classify own-property
   names on the two DOM nodes: `react_fiber` /
   `react_internal` / `react_props` / `none`. Never persist the
   random suffix after `$`. Do not open `Ember.View.views`.
5. **Official Fiber fields only.** If a fiber `objectId` exists,
   read `tag`, `type`, `elementType`, `stateNode`, `return`,
   `child`, `sibling`, `pendingProps`, `memoizedProps`,
   `memoizedState`. Walk `return` at most 8. Do not walk the
   whole tree. Do not invoke.
6. **Type token.** Classify `type` / `elementType` name to
   `{picker, select, combobox, autocomplete, contact, other,
   none}`. Never persist the raw string.
7. **Host class.** Classify `stateNode` as `input` / `overlay` /
   `wrapper` / `other` / `none` against the known contact input,
   the `dx=242` overlay, and the wrapper. `unique_fiber_host` is
   true only when exactly one `other` host remains.
8. **No setter invoke.** Do not `Runtime.callFunctionOn` to run
   methods. Do not `dispatch` or `setState`.
9. **Unique normal action.** True only when exactly one
   allowlisted open/select/filter action is present **and**
   `unique_fiber_host` is true. A method with no new host is
   `UI_CHANGED`.
10. **Click / customer gate.** Create a tagged customer and
    perform one named UI action only after
    `unique_normal_action=true`. Else no customer, no click.
11. **Cleanup.** If a customer was created, delete it. Prove
    absence in a fresh session. Commit allowlisted summary only.
12. **Vision.** Live test may write `author=live_test` and
    `reviewer_verdict=pending_review` only.
13. **No remap.** Preview `tool_name` waits for a later slice
    after independent accept + purge.
14. **Live test short-circuit.** After the dump is delivered,
    later `ui-full` must verify the file and must not remake
    Ember inspect or repeat a closed click.
