## Contract freeze (research119)

### Tool

- **Name:** `ui_reports_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  report type, period, credential, local file path, digest, destination, or
  export payload.
- **Success:** non-PII only:
  - `path_class`: class under `/:org_slug/reports-all` — accept
    `/:org_slug/reports-all` **or**
    `/:org_slug/reports-all/{profit-and-loss|balance|trial-balance}` with
    optional period/year query (Billy may default tab and append `period=…`).
  - `heading`: `Rapporter`
  - `export_action_visible`: bool true when **Eksport** is visible
    (observe only; never click).
  - `shell_markers_present`: bool for hub tab markers
    (Resultatopgørelse / Balance / Saldobalance present as labels) and/or
    shared shell nav markers without dumping page text or account figures.
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (Upsedasse/error shell, bare `/reports`
  soft chrome, exports/vat/annual paths, wrong path class, missing h1,
  classification failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens,
  account amounts, or customer PII.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Direct goto `https://mit.billy.dk/{org_slug}/reports-all` (research119
     freeze target). Do **not** treat bare `/reports` as success.
  5. Classify path with regex equivalent to
     `^/[^/]+/reports-all(?:/(?:profit-and-loss|balance|trial-balance))?$`
     (optional query params allowed).
  6. Signature: path class match + h1 `Rapporter` + not login + not
     Upsedasse/error shell + tab markers (Resultatopgørelse / Balance /
     Saldobalance). Do **not** require a specific default sub-tab (Billy may
     remember last tab).
  7. Reject bare `/reports`, soft aliases, exports, vat-declarations,
     annual_reports, and transactions paths as `UI_CHANGED` for this tool.
- **Hard bans:** never click Eksport / Download / Generate / print / submit;
  never invent API report tools; never treat sibling families as success.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
