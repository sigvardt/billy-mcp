## Contract freeze (research126 company / Virksomhed open shell)

### Tool

- **Name:** `ui_settings_company_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  credential, local file path, digest, destination, or write payload.
- **Success:** non-PII only:
  - `path_class`: `/:org_slug/settings` (canonical class without query).
  - `heading`: `Indstillinger` (exact).
  - `shell_kind`: literal `settings_company` (or equivalent stable enum
    distinguishing company panel from soft_empty / other settings panels /
    sibling shells).
  - `company_panel_markers_present`: bool true when company panel markers are
    visible (require `Navn og adresse` and `Kontaktinformation` at minimum;
    optional observation of `Virksomhedsikon` / `Ejere` without logging PII).
  - Optional observe-only: `save_cta_markers_present` when `Gem ændringer` text
    is visible (**no page dump**, no org names, no person names).
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` when any of:
  - soft aliases leaving non-hub settings path (`settings/company`,
    `settings/vat`, `settings/users`, `settings/list`, `indstillinger`, …)
  - hub open but **wrong panel** (Regnskab / Faktura / empty subscription body)
    if the product navigates only bare `settings` this is mainly a safeguard
    for mis-classification
  - Upsedasse / error shell / plan-gate as sole state / login form present
  - heading not `Indstillinger` on settings path
  - sibling shells (Lagermodul, Fordele, Eksportér data, Overblik, products)
- **Never:** click Gem ændringer / Tilføj ejer / upload / Opret* / Opgrader;
  invent `api_settings_*`; open other settings panels as this tool's success.

### Navigation

1. Ensure authenticated READY session via existing browser auth path.
2. Prefer direct `https://mit.billy.dk/{org_slug}/settings` (bare settings only).
3. Do **not** use nested aliases (`settings/company`, `settings/accounting`,
   …) for success navigation of this tool.
4. Independent second session (fresh profile or equivalent) re-opens the same
   path and asserts path / h1 Indstillinger / company panel markers. **No**
   API read-back.
