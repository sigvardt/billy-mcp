with root verification, so it is delegated rather than self-reviewed. Create a

```bash

  --path=/Volumes/ssd_1/Repositories/billy-mcp/.worktrees/main.billy_complete \
  --agent=grok --base=main.billy_complete --scope=wiki \
  --max-depth=0 --max-children=0 --max-descendants=0
```
