## Design choices

1. **TDD first (`728BD2E4`).** Confirm honesty-16 still length 16
   and red. First product edit is a failing unit fixture. Current
   descendant dump flags (`unique_target=false`,
   `wrapper_handler_guard=none`, `visible_descendant_count=2`, no
   Ember keys) fail `kunde_ember_missing_keys`. Run it. Capture
   the failure. Then implement. Do not reuse
   `REQUIRED_KUNDE_DESCENDANT_KEYS` as this fixture.
2. **Honesty-16 stays red.** Do not remap invoice tools.
3. **Read-only first.** The live inspect does not need a tagged
   customer. Open `/:org_slug/invoices/new`. Hold the proved
   `pickerfield` wrapper. CDP `Runtime.getProperties` only.
4. **Official Ember lookup.** If `window.Ember` and
   `Ember.View.views` exist and the wrapper id class is
   `ember_digit`, look up the view without persisting the raw id
   (Ember 1.10 debugging guide). Else read element own-properties
   only. `lookup_class` is `view_registry` /
   `element_properties` / `none`.
5. **No getter invoke.** Do not call `Ember.get` or `view.get`.
   Do not `Runtime.callFunctionOn` to run methods. Computed
   getters can mutate.
6. **Unique normal action.** True only when exactly one
   allowlisted open/select/filter action is present **and** a
   unique unused DOM target exists. A method with no new DOM
   target is `UI_CHANGED`.
7. **Click / customer gate.** Create a tagged customer and
   perform one named UI action only after
   `unique_normal_action=true`. Else no customer, no click.
8. **Cleanup.** If a customer was created, delete it. Prove
   absence in a fresh session. Commit allowlisted summary only.
9. **Vision.** Live test may write `author=live_test` and
   `reviewer_verdict=pending_review` only.
10. **No remap.** Preview `tool_name` waits for a later slice
    after independent accept + purge.
11. **Live test short-circuit.** After the dump is delivered,
    later `ui-full` must verify the file and must not repeat a
    closed click.
12. **No React this slice.** If Ember has no unique action,
    record `UI_CHANGED` and stop. React fiber is a later parent
    slice.
