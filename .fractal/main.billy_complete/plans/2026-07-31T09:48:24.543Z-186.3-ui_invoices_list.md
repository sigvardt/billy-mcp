## Contract freeze (research102)

### Tool

- **Name:** `ui_invoices_list`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  filter, or credential fields.
- **Success:** non-PII only, e.g.
  - `path_class`: literal `/:org_slug/invoices` (or equivalent redacted form)
  - `heading`: literal class matching observed h1 `Fakturaer` (exact Danish
    label observed; do not assert org name)
  - `create_action_visible`: bool for CTA text `Opret faktura` (no click)
  - optional `shell_markers_present`: bool for ≥1 shared shell marker
    (Overblik / Fakturering / Menu) without dumping page text
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (error shell, wrong path, missing h1/CTA),
  `EGRESS_DENIED`, `BILLY_ERROR`. Messages must not include org slug, org name,
  email, password, tokens, or customer invoice text.
- **Navigation:**
  1. Open persistent MCP profile under fixed egress.
  2. If login signature present, do **not** auto-login inside this tool unless
     product already documents that behaviour — prefer fail `AUTH_REQUIRED`
     and require callers to run `auth_login_start` + `auth_login_wait` first
     (matches existing auth tool ownership). Live tests call auth tools then
     `ui_invoices_list`.
  3. Resolve org path segment only from current authenticated session URL or
     outside-git identity file written by `auth_login_wait`. Never accept
     caller-supplied free URL. Never log the slug.
  4. `page.goto` only `https://mit.billy.dk/{slug}/invoices` (slug in-memory).
  5. Wait for settle (networkidle with timeout fallback).
  6. Classify: path must match `^/[^/]+/invoices$`; h1 exact `Fakturaer`;
     CTA present; reject if login signature, challenge, or error markers
     (`Upsedasse`, `Log ind igen`) appear.

### Explicit non-actions

- No click on `Opret faktura` / `Mere`.
- No row open, filter fill, or export.
- No API client calls; browser egress remains deny-by-default except reviewed
  path allows for login/bootstrap.
