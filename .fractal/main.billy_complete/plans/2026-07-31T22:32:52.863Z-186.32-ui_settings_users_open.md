## Contract freeze (research131 users / Brugere open shell)

### Tool

- **Name:** `ui_settings_users_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  credential, local file path, digest, destination, or write payload.
- **Success:** non-PII only:
  - `path_class`: `/:org_slug/settings` (canonical class without query; bare
    hub leaf; SPA does **not** keep `/settings/users`).
  - `heading`: `Indstillinger` (exact).
  - `shell_kind`: literal `settings_users`.
  - `users_panel_markers_present`: bool true when required markers are
    visible — require h2 set includes **`Brugere`** and
    **`Revisorer og bogholdere`** (strict pair; both).
  - Must be **distinct from company**: company panel h2 pair
    (`Navn og adresse` + `Kontaktinformation`) must **not** both classify as
    the active panel signature. Company **Ejere** is not users success.
  - Must be **distinct from accounting**: accounting panel trio
    (`Regnskab` + `Køb` + `Kontoplan`) must **not** classify as success.
  - Must be **distinct from invoicing**: invoicing panel
    (`Faktura` + `Produkter` + (`Betalingsmetoder` or `Standard fakturalogo`))
    must **not** classify as success.
  - Must be **distinct from user/Profil**: user panel
    (`Profil` + `Billede` + `Sprog og tema` + `Skift adgangskode`) must
    **not** classify as success.
  - Must be **distinct from vat/Momssatser**: vat panel triad
    (`Regelsæt` + `Satser for salg` + `Satser for køb`) must **not** classify
    as success.
  - Optional observe-only: `invite_cta_markers_present` when `Invitér` /
    `Invitér bruger` / `Invitér revisor` / `Overdrag ejerskab` text is visible
