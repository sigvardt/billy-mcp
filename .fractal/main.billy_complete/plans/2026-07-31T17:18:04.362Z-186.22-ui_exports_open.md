## Contract freeze (research121 exports shell)

### Tool

- **Name:** `ui_exports_open`
- **Input:** empty strict model (`extra=forbid`) — no URL, selector, org id,
  period, credential, local file path, digest, destination, or write/export
  payload.
- **Success:** non-PII only:
  - `path_class`: `/:org_slug/exports` (optional query params allowed; product
    may always report the canonical class without query for dual-session
    stability, matching reports/vat pattern).
  - `heading`: `Eksportér data`
  - `shell_markers_present`: bool for shell markers (h1 + export hub chrome such
    as report-shortcut labels and/or Eksport button presence **without**
    clicking; never dump page text, org names, or customer lists).
  - Optional: `saft_export_cta_observed`: bool true when text
    `Eksportér som SAF-T` is present (observe only; **must not** green
    `ui.discovery.saft_exports`).
- **Errors:** `AUTH_REQUIRED` (login signature), `AUTH_INTERACTION_REQUIRED`
  (challenge selectors), `UI_CHANGED` (Upsedasse/error shell, soft aliases,
  reports-all/vat/annual/transactions/settings paths, wrong path class, missing
  h1, classification failure), `EGRESS_DENIED`, `BILLY_ERROR`.
  Messages must not include org slug, org name, email, password, tokens, or
  customer PII.
- **Navigation:**
  1. Open MCP profile under fixed egress (`coverage/browser_egress.yaml`).
  2. If login signature present → `AUTH_REQUIRED` (callers use auth tools first).
  3. Resolve org slug from session URL or outside-git identity file only.
  4. Direct goto `https://mit.billy.dk/{org_slug}/exports` (research121 freeze
     target). Do **not** treat soft aliases as success.
  5. Classify path with regex equivalent to `^/[^/]+/exports$` (optional query
     params allowed).
  6. Signature: path class match + h1 `Eksportér data` + not login + not
     Upsedasse/error shell + shell chrome markers. Empty table is **valid**
     (exports hub is category cards, not a data table).
  7. Reject soft aliases and sibling paths as `UI_CHANGED` for this tool
     (including `annual_reports` Upsedasse, `reports-all`, `vat-declarations`,
     bare wrong export spellings if empty chrome).
- **Hard bans:** never click Eksport / Download / Eksportér som SAF-T /
  generate / print / submit; never invent API export tools; never treat sibling
  families as success; never call live API; never download files.
- **Session:** no API token; no screenshot persistence in production tool path;
  live test captures frames only outside git for vision then purges.
