# decisions

Use Grok only. Do not spawn children.

Do not green coverage rows. Do not invent `ui_annual_*` tools. Do not run live API tests. Do not send invoices or emails, make payments, submit VAT or filings, or change users, access, tokens, or subscription.

Live UI submit waits for an explicit root go-ahead. Contacts is first in line. After a grant: unique tagged names, independent second UI session read-back, four-state capture, purge raw frames, store only a non-sensitive vision record.

If a submit cannot be deleted, stop and report the blocker. Do not post irreversible ledger entries.

`register_ui_ledger_write_tools` receives only `server` and `UiWriteProtocol`. There is no browser or HTTP client. Execute consumes the ticket and returns `submitted=false` with a blocker. Do not construct `BrowserRuntime` or `BillyHttpClient` from this module.

Daybook create/delete are the only live-eligible pair, and only after root grants a slot and a matching delete is proven on the same tagged `MCP-LEDGER-` name. Daybook transaction create and Posteringer create stay unsubmitted until cleanup is proven.
